Поддержка суффикса
@2x не является обязательным стандартом для всех серверов, и универсального способа «спросить» сервер о его поддержке через URL нет.
Вот основные способы определить поддержку и список популярных сервисов на 2025 год:
1. Как проверить поддержку программно?
Поскольку стандартного API для этого нет, библиотеки обычно используют один из двух подходов:

    Метод пробного запроса: Отправить один запрос на тестовый тайл с @2x (например, .../0/0/0@2x.png). Если сервер вернул 200 OK и картинку размером 512x512 — поддержка есть. Если 404 или 403 — нет.
    Анализ строки шаблона: Если пользователь передает вам URL, вы можете искать в нем специальные плейсхолдеры, такие как {r} (используется в Leaflet для Retina). Если {r} есть в строке, значит, URL готов к подстановке @2x. 

2. Кто поддерживает @2x (актуально на 2025 год)
Многие крупные провайдеры перешли на векторные тайлы, но для растра поддержка следующая:
Провайдер 
	Поддержка @2x / HiDPI	Формат URL
OpenStreetMap (стандарт)	Нет (официально)	Только стандартные 256px тайлы.
MapTiler	Да	.../{z}/{x}/{y}@2x.png
Thunderforest	Да	Требуется API-ключ.
Mapbox (Raster)	Да	.../{z}/{x}/{y}@2x.png
Stamen / Stadia Maps	Да	Поддерживают через свои API.
Google Maps (Tiles API)	Да	Через параметр scale=2 в запросе.
3. Что делать, если @2x не поддерживается?
Если вы получили обычную ссылку tile.openstreetmap.org, ваш текущий метод с 1 / dpr остается лучшим решением для читаемости.
Почему это происходит:
Стандартные тайлы OSM имеют фиксированный размер 256x256 пикселей с мелким текстом, рассчитанным на старые мониторы (72–96 DPI). На современных смартфонах (300+ DPI) этот текст физически становится в 3–4 раза меньше. Уменьшая виртуальное разрешение холста (ваш подход), вы заставляете браузер растягивать эти 256 пикселей на большее физическое пространство, возвращая тексту читаемый размер. 
Рекомендация для вашей библиотеки:
Добавьте в настройки слой-флаг detectRetina.

    Если true и сервер поддерживает @2x (или есть плейсхолдер {r}): запрашивайте @2x и рисуйте в полном разрешении.
    Если true, но сервер не поддерживает @2x: используйте ваш метод с 1 / dpr, чтобы принудительно увеличить масштаб карты для пользователя.

В 2025 году векторные тайлы являются стандартом для производительных картографических приложений, так как они позволяют динамически менять стили, плавно масштабировать карту без потери качества и значительно экономят трафик
. 
Основные провайдеры векторных данных (Vector Tiles API):
1. Коммерческие лидеры (с бесплатными лимитами)

    Mapbox: Самый популярный сервис. Предоставляет до 200 000 бесплатных запросов к Vector Tiles API в месяц. Использует проприетарную, но широко принятую спецификацию стилей.
    MapTiler: Прямой конкурент Mapbox, предлагающий векторные тайлы в форматах MVT/PBF. Удобен для интеграции с MapLibre.
    Stadia Maps / Stamen: Предлагают векторные тайлы на базе OSM с акцентом на эстетичные стили (например, Toner или Terrain).
    Geoapify: Предоставляет векторные и растровые тайлы на базе OpenStreetMap с различными стилями (osm-bright, klokantech и др.). 

2. Крупные экосистемы

    Google Maps Platform: Поддерживает векторные карты в своих SDK, однако доступ к «сырым» векторным тайлам для сторонних библиотек ограничен их лицензией.
    Yandex Maps API: В 2025 году предлагает бесплатный Tiles API для определенных сценариев, активно развивает векторные подложки.
    ArcGIS (Esri): Полноценная поддержка векторных сервисов (Vector Tile Services), ориентированная на корпоративный сектор. 

3. Open Source и Self-hosted (свои серверы)
Если вы хотите использовать векторные данные без оплаты за запросы, можно развернуть свой сервер:

    Martin: Высокопроизводительный сервер на Rust, генерирующий векторные тайлы (MVT) напрямую из базы данных PostGIS «на лету».
    TileServer GL: Позволяет раздавать векторные тайлы и на их основе генерировать растровые для старых клиентов.
    Protomaps: Новая технология (PMTiles), позволяющая хранить всю карту в одном файле на S3-хранилище и запрашивать данные через HTTP Range Requests без активного сервера. 

Для вашей библиотеки:
Векторные тайлы обычно передаются по ссылке вида:
api.provider.com{z}/{x}/{y}.vector.pbf?access_token=...
В отличие от растра, они требуют клиентскую библиотеку для отрисовки (например, MapLibre GL JS или OpenLayers), которая превратит «цифры» координат в видимые линии и полигоны с помощью WebGL.
