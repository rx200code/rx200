Для вашей библиотеки я подготовил список наиболее надежных и актуальных на 2025 год источников растровых тайлов.
1. OpenStreetMap (Стандарт)
Самый известный источник. Подходит для разработки и небольших проектов.

    URL: https://tile.openstreetmap.org/{z}/{x}/{y}.png
    Данные: Детальная карта мира, обновляемая сообществом.
    Условия: Бесплатно.
    Лимиты: Нет строгого числа запросов, но запрещено массовое скачивание (bulk downloading) и использование в высоконагруженных коммерческих приложениях без собственного кэширующего сервера. Требуется обязательная подпись (Attribution). 

2. Яндекс Карты (Tiles API)
В июне 2025 года Яндекс расширил бесплатный доступ для бизнеса. 

    URL: Нужен API-ключ. Пример: core-renderer-tiles.maps.yandex.net{x}&y={y}&z={z}&lang=ru_RU (формат может меняться, используйте JS SDK для стабильности).
    Данные: Лучшее покрытие по РФ и СНГ, детальные адреса.
    Условия: Бесплатно для сайтов и приложений (с 2025 года лимиты стали очень щедрыми для базового слоя).
    Лимиты: Зависят от типа лицензии, но для большинства малых и средних проектов теперь доступны без оплаты. 

3. MapTiler
Один из лучших современных провайдеров с поддержкой HiDPI/Retina.

    URL: api.maptiler.com{z}/{x}/{y}.png?key=ВАШ_КЛЮЧ
    URL (Retina): api.maptiler.com{z}/{x}/{y}@2x.png?key=...
    Данные: Качественные стили (Basic, Streets, Satellite, Outdoor).
    Условия: Есть бесплатный план для некоммерческого использования и R&D.
    Лимиты: До 100 000 запросов в месяц на бесплатном плане. 

4. Stadia Maps (включая стили Stamen)
Отличный выбор для красивых дизайнерских карт.

    URL: tiles.stadiamaps.com{z}/{x}/{y}.png?api_key=...
    Данные: Элегантные стили (черно-белые Toner, акварельные Terrain).
    Условия: Бесплатно для разработки и некоммерческих проектов.
    Лимиты: До 200 000 запросов в месяц на бесплатном уровне. 

5. Thunderforest
Специализируются на тематических картах (транспорт, велодорожки).

    URL: tile.thunderforest.com{z}/{x}/{y}.png?apikey=...
    Данные: Специальные слои: CycleMap (вело), Transport, Outdoors, Landscape.
    Условия: Требуется регистрация. Есть бесплатный уровень для хобби-проектов.
    Лимиты: Примерно 150 000 тайлов в месяц бесплатно. 

6. Esri (ArcGIS Online)
Профессиональные ГИС-данные, включая отличные спутниковые снимки.

    URL: server.arcgisonline.com{z}/{y}/{x}
    Данные: Спутник (World_Imagery), топография, улицы.
    Условия: Бесплатно для некоммерческого использования и разработки.
    Лимиты: Достаточно высокие для большинства приложений, но требуют регистрации для получения ключа в коммерческих целях.

Для вашей библиотеки, помимо базовых карт, крайне полезны два типа данных:
карты высот (DEM) для построения рельефа и карты треков (активности сообщества).
1. Карты высот (Digital Elevation Model — DEM)
Эти тайлы выглядят как странные цветные картинки, но каждый пиксель в них — это зашифрованная высота в метрах.

    Mapbox Terrain-RGB
        URL: https://api.mapbox.com/v4/mapbox.terrain-rgb/{z}/{x}/{y}.pngraw?access_token=ВАШ_КЛЮЧ
        Суть: Высота считается по формуле: высота = -10000 + ((R * 256 * 256 + G * 256 + B) * 0.1).
        Лимиты: До 50 000 бесплатных запросов в месяц.
    MapTiler Terrain RGB
        URL: api.maptiler.com{z}/{x}/{y}.png?key=ВАШ_КЛЮЧ
        Суть: Аналогичный формат кодирования высоты в RGB.
        Лимиты: Входит в бесплатный пакет до 100 000 запросов.
    OpenTopoMap (Визуальный рельеф)
        URL: https://{s}.tile.opentopomap.org/{z}/{x}/{y}.png
        Данные: Это не сырые высоты, а готовая топографическая карта с линиями высот и тенями.
        Условия: Бесплатно (фонд OSM). 

2. Карты треков (Слои активности)
Эти слои обычно накладываются поверх основной карты, чтобы показать популярные маршруты.

    OSM GPS Traces (Сырые треки пользователей)
        URL: https://{s}.gps-tile.openstreetmap.org/lines/{z}/{x}/{y}.png
        Данные: Все GPS-треки, когда-либо загруженные пользователями в OSM. Помогает видеть реальные тропы, которых нет на отрисованной карте.
        Условия: Бесплатно.
    Strava Heatmap (Популярность маршрутов)
        URL: Требует сложной авторизации (через куки сессии), прямой публичной ссылки без ключей нет.
        Данные: Самая точная «тепловая карта» бега и велопоездок в мире.
    Thunderforest (Специализированные треки)
        Велодорожки: tile.thunderforest.com{z}/{x}/{y}.png?apikey=...
        Транспорт: tile.thunderforest.com{z}/{x}/{y}.png?apikey=...
        Лимиты: До 150 000 тайлов в месяц бесплатно.

3. Спутниковые снимки (для сопоставления с треками)

    Esri World Imagery
        URL: server.arcgisonline.com{z}/{y}/{x}
        Данные: Детальный спутник по всему миру.
        Условия: Бесплатно для некоммерческого использования. 

Совет для кода: При использовании Terrain-RGB тайлов важно отключать интерполяцию (сглаживание) браузером, иначе при расчете высоты между пикселями вы получите неверные значения. Используйте CSS image-rendering: pixelated; для Canvas с картой высот.

Если будете реализовывать поддержку карт высот (Terrain-RGB), помните один нюанс: в отличие от обычных картинок, эти тайлы нельзя просто рисовать на экране. Их нужно загружать через fetch или рисовать на невидимый canvas, чтобы потом через ctx.getImageData() вытаскивать значения каналов R, G и B для расчетов.
Вот финальный совет на 2025 год: если планируете добавлять Яндекс.Карты, обязательно проверьте их новую лицензию «API Яндекс Карт» — они сейчас активно конкурируют с Google и OSM, предлагая очень выгодные условия для разработчиков библиотек.
